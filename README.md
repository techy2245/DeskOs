# DeskOS

> A dedicated touchscreen companion for your desk that brings currently playing media and notifications from your connected devices into one place.

## Overview

DeskOS is a tablet-sized touchscreen device designed to keep important information from your phone and laptop visible without constantly switching between devices.

The main interface focuses on currently playing media. Notifications remain available through a dedicated notification view.

DeskOS is designed around the devices a user already owns rather than requiring individual integrations with every application.

## Core Features

### Now Playing

DeskOS displays:

- Album artwork
- Song title
- Artist
- Album/source information when available
- Playback progress
- Play/pause
- Previous/next
- Volume controls where supported

Playback controls on DeskOS are intended to control the media session on the connected device.

### Notifications

The top bar always displays:

- Current time
- Notification icon
- Number of unread notifications

Notification contents remain hidden until the notification view is opened.

The notification view displays notification information received from connected devices.

Notifications can be dismissed from DeskOS.

## Multiple Devices

DeskOS is intended to connect to both a phone and a laptop.

If multiple media sessions are available, the user can swipe between them and select which session is displayed and controlled.
